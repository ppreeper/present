# Bundled Fonts

The fonts in this directory are self-hosted subsets of open-source families,
downloaded from [Fontsource](https://fontsource.org/) via jsDelivr and packaged
as WOFF2 with `unicode-range` subsetting. Each family is licensed under the
[SIL Open Font License, Version 1.1](https://scripts.sil.org/OFL); the full
licence text ships as `LICENSE` in each family's directory.

| Family | Directory | License |
|--------|-----------|---------|
| Inter | `inter/` | SIL OFL 1.1 |
| Source Sans 3 | `source-sans-3/` | SIL OFL 1.1 |
| IBM Plex Sans | `ibm-plex-sans/` | SIL OFL 1.1 |
| Source Serif 4 | `source-serif-4/` | SIL OFL 1.1 |
| Merriweather | `merriweather/` | SIL OFL 1.1 |
| EB Garamond | `eb-garamond/` | SIL OFL 1.1 |
| JetBrains Mono | `jetbrains-mono/` | SIL OFL 1.1 |
| Source Code Pro | `source-code-pro/` | SIL OFL 1.1 |
| IBM Plex Mono | `ibm-plex-mono/` | SIL OFL 1.1 |

`fonts.css` is generated by [`tools/fetch-fonts.sh`](../../../../tools/fetch-fonts.sh);
regenerate with that script rather than editing files here by hand.
